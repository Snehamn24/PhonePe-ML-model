# PhonePe Transaction Insights Dashboard

## Overview
This project analyzes PhonePe transaction data using Python, SQL, and Streamlit to generate meaningful business insights.

## Features
- Interactive filters (Year, State)
- KPI metrics (Transactions & Amount)
- State-wise analysis
- Device brand distribution
- Transaction trends over time
- Insurance analysis
- Raw data view

## Tech Stack
- Python
- Pandas
- SQLite
- Streamlit
- Matplotlib & Seaborn

## Dataset
PhonePe Pulse GitHub dataset

## How to Run
```bash
streamlit run app.py
```

## Insights
- Maharashtra & Karnataka lead in transactions
- Xiaomi is the most used device brand
- Digital transactions are growing yearly
- Seasonal spikes observed in Q4
